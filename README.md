# Nahuatl Transcoder (Rust)

A Rust implementation of Edward H. Trager's Nahuatl transcoding system. The project combines the original 2016 Nahuatl abugida transcoder from [NahuatlTools](https://github.com/piratical/NahuatlTools) with concepts and mappings from the later [NOCE (Nahuatl Orthography Conversion Engine)](https://github.com/piratical/noce) project. It supports conversion from Latin-based Nahuatl orthographies into an internal Atomic representation and the NahuatlOne abugida encoding, together with Trager-to-Atomic decoding support.

The implementation aims to preserve and extend the behavior of the original codebase, with output validated against a golden corpus generated by the original transcoder.

## Features

* Classical and modern Nahuatl orthography normalization
* Latin orthography → Atomic conversion
* Atomic → NahuatlOne abugida conversion
* Trager abugida → Atomic conversion
* NOCE-compatible Atomic orthography processing
* Classical Nahuatl → modern SEP orthography converter (`c2m`)
* Unicode-safe Rust implementation
* Command-line interface
* Corpus-based regression tests

## Build

```bash
cargo build --release
```

## Usage

Convert a text file, with each line processed independently:

```bash
cargo run -- words.txt
```

Or run the compiled binary:

```bash
./target/release/nahuatl_transcoder words.txt
```

## c2m

The repository includes a second command-line utility, `c2m`, which converts Classical Nahuatl orthography to modern SEP orthography.

Examples:

```text
quetzal  -> ketsal
ce       -> se
ci       -> si
cu       -> ku
huitzil  -> uitsil
```

Run it with:

```bash
cargo run --bin c2m -- words.txt
```

Or run the compiled binary:

```bash
./target/release/c2m words.txt
```

The converter:

* Normalizes accented and long vowels
* Converts classical spellings to modern SEP spellings
* Preserves the digraph `ch`

## NOCE and Pipeline

The architecture incorporates the Atomic ↔ Trager model introduced in the later NOCE project:

* **Atomic Intermediate Representation:** Derived from the [NOCE](https://github.com/piratical/noce) project, it provides a normalized phonemic representation used internally by the converter for robust orthography handling and internal normalization.
* **Modules (`abugida.rs`, `atomic.rs`, `orthography.rs`, `trager.rs`):** Handle the decoupled processing of orthographic mapping, phonemic atomization, and abugida rendering.

## Background

Nahuatl is a Uto-Aztecan language spoken in Mexico. Classical Nahuatl was written using the Latin alphabet after the arrival of the Spanish in the sixteenth century. This project began as a Rust port of Edward H. Trager's original C++ transcoder from [NahuatlTools](https://github.com/piratical/NahuatlTools). The implementation has since been extended with additional functionality inspired by his later [NOCE](https://github.com/piratical/noce) project, including Atomic orthography support and Trager abugida interoperability.
